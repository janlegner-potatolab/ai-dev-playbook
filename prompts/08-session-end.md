# 08 · Session end

Use when a session wraps up. The protocol is executed, not asked (guide § 8.4).

```text
Close this session:
1. Git: everything committed, pull request open, reviewed and merged where you may merge. Do not
   stop at an open pull request and do not ask whether to commit.
2. State: rewrite the "Where it stands" section of the issue (date, assignment, criteria, done,
   next, blockers, PR, branch, decisions).
3. Clean up the worktrees, temporary files, processes and containers this session started.
4. Every real defect you met is a new issue, not a note in a file.
5. Report: done in this session / waiting on my decision / what follows. First sentence: which
   acceptance criterion moved; if none, say so first. At most 12 lines.
```
